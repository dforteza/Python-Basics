# 00 - Repaso

Ejercicios de los apuntes del curso pasado. Cada fichero `ej_X_Y.py` tiene
solo el enunciado; las soluciones están en [`../docs/soluciones`](../docs/soluciones).
Sufijo `_w` = con `while`, `_f` = con `for`.

## Método
1. Resuelve sin mirar la solución.
2. Si te atascas: primero la teoría (`docs/teoria`), luego la solución.
3. Compara al terminar: ¿hay una forma más pythónica?

## Selección mínima (si vas con prisa)
| Ejercicio | Qué repasa |
|-----------|------------|
| `02_cadenas/ej_2_6.py` | `split` + desempaquetado |
| `04_bucles/ej_4_7_w.py` | `%` y `//` |
| `04_bucles/ej_4_10.py` | bucle con estado (el más largo) |
| `05_listas/ej_5_4.py` | `enumerate` y comprensiones |
| `05_listas/ej_5_13.py` | modificar una lista mientras la recorres |
| `06_diccionarios/ej_6_6.py` | `in`, `get` en diccionarios |
| `06_diccionarios/ej_6_8.py` | diccionario + `max` |

## Ejecutar
```bash
python3 04_bucles/ej_4_10.py
```
